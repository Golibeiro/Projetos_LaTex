Nesta pasta, está contido o projeto de um sistema de cadastro para itens de um inventário de uma loja feito em C,
ele funciona com a função de adição, e analíse de itens inscritos no sistema.
também estão contidos os dois relatórios referentes ao projeto, feitos pela ferramenta LaTex, 
pelo Overlead (site de edição da linguagem de marcação).

Neste sistema, tem uma interface simples, e direta, além das funções definidas de Create and Read.

Entre as funções requisitadas que o código precisava ter, estavam entre elas:
1- Solicitar ao usuário quantos produtos serão cadastrados.
2- Aceitar valores de 1 a 10.
3- Encerrar o programa quando solicitado.
4- Fazer uso de alocação dinâmica, e alocar a quantidade necessária.
5- Pedir informações para o cadastro do produto (Código, nome, preço e quantidade).
6- Fazer uma interface que liste os conteúdos.
7- Utilizar o comando para liberação de memória do sistema.
8- E outros conceitos aprendidos durante os estudos da linguagem C (Vetores, funções, ponteiros, laços, bibliotecas, e entre outros).
